# 数据字典（说明书）

> 本文档说明 `src/parser/parse.py` 从 CS2 demo 解析出的全部结构化数据。
> 数据来源：`awpy 3.3.0`。行数以示例 demo（`2026-11-16_de_dust2_1.dem`，de_dust2，19 回合）为准，不同 demo 行数不同。
>
> **数据存放位置**：`data/processed/<demo名>/tables/`（Parquet 表 + header.json + manifest.json）。
> 图片在 `<demo名>/figures/`，分析表格在 `<demo名>/reports/`。

---

## 1. 通用约定

| 概念 | 说明 |
|------|------|
| **坐标系统** | Hammer 单位，`x`/`y` 为平面坐标，`z` 为垂直高度（向上为正）。画热力图时需与地图底图对齐 |
| **阵营 `side`** | `terrorist`（T）、`counter-terrorist`（CT）；观察者/机器人可能为 `null` |
| **队伍编号** | 2 = Terrorist，3 = Counter-Terrorist（如 `rounds.winner`） |
| **`steamid`** | Steam 64 位 ID，`0` 表示 GOTV 观察者或机器人 |
| **`tick`** | 游戏刻，demo 按 tick 推进。本 demo 约 64 tick，`tick / 64 ≈ 秒` |
| **`entity_id` / `entity_serial`** | 游戏内实体编号，用于关联同一实体（含道具、炸弹） |
| **编码** | 所有 Parquet 均为 UTF-8，中文昵称安全 |

## 2. 表清单速览

| 表 | 行数(示例) | 说明 | 主要用途 |
|----|-----------|------|---------|
| `header.json` | — | demo 元信息（JSON） | 地图名、时长 |
| `players` | 12 | 本场玩家列表 | 身份映射 |
| `stats` | 11 | 每名玩家整场战绩 | 战绩面板 |
| `rounds` | 19 | 每个回合的结果 | 失守区域判定 |
| `kills` | 170 | 每次击杀（含双方坐标） | 交火/死亡热区 |
| `damages` | 678 | 每次伤害事件 | 更细的交火分析 |
| `shots` | 3,649 | 每次开枪（含朝向） | 枪法/架点分析 |
| `round_economy` | 38 | 每回合每阵营经济 | 推荐系统 context |
| `grenades` | 34,340 | 每次道具投掷 | 战术打法分析 |
| `bomb` | 122 | 炸弹相关事件 | 攻防节奏分析 |
| `snapshots_1s` | 20,187 | 每秒玩家状态快照 | ⭐ 走位热力图主数据源 |

## 3. 各表字段详解

### 3.1 `header.json`（元信息）

| 字段 | 示例值 | 说明 |
|------|--------|------|
| `map_name` | `de_dust2` | 地图名 |
| `server_name` | `Counter-Strike 2` | 服务器名 |
| `client_name` | `SourceTV Demo` | 录制来源 |
| `build_num` | `10955` | 游戏构建号 |
| `playback_ticks` | `130645` | 总 tick 数 |
| `playback_time` | `2041.33` | 总时长（秒） |

---

### 3.2 `players`（本场玩家）

| 字段 | 类型 | 说明 |
|------|------|------|
| `steamid` | UInt64 | Steam ID（0 = 观察者/机器人） |
| `name` | String | 昵称 |
| `side` | String | 阵营（`terrorist` / `counter-terrorist` / null） |
| `team_clan_name` | String | 战队名（通常为 null） |

---

### 3.3 `stats`（玩家整场战绩）

| 字段 | 类型 | 说明 |
|------|------|------|
| `steamid` | UInt64 | Steam ID |
| `name` | String | 昵称 |
| `rounds_played` | Int32 | 出场回合数 |
| `kills` / `deaths` / `assists` | Int32 | 击杀 / 死亡 / 助攻 |
| `flash_assists` | Int32 | 闪光助攻次数 |
| `headshot_kills` | Int32 | 爆头击杀数 |
| `headshot_pct` | Float32 | 爆头率（%） |
| `opening_kills` | Int32 | 首杀次数（回合内第一个击杀） |
| `opening_deaths` | Int32 | 首死次数 |
| `traded_deaths` | Int32 | 被补枪的死亡次数（死后击杀者被队友击杀） |
| `multikill_2k` ~ `multikill_5k` | Int32 | 2~5 连杀次数 |
| `kast` | Float32 | KA%：击杀+助攻+存活+被交易 的回合占比 |
| `adr` | Float32 | 场均伤害（每回合平均伤害） |
| `clutches_played` / `clutches_won` | Int32 | 残局参与 / 获胜次数 |
| `clutch_1v1` ~ `clutch_1v5` | Int32 | 各人数残局次数 |
| `utility_damage` | Int32 | 道具造成的伤害 |
| `flashes_thrown` | Int32 | 投掷闪光数 |
| `enemies_flashed` | Int32 | 闪到敌人的次数 |
| `flash_duration_dealt` | Float32 | 对敌造成致盲总时长（秒） |

---

### 3.4 `rounds`（回合结果）

| 字段 | 类型 | 说明 |
|------|------|------|
| `round_num` | Int32 | 回合号（从 1 开始） |
| `start_tick` | Int32 | 回合开始 tick |
| `freeze_end_tick` | Int32 | 冻结时间结束 tick（可移动时刻） |
| `end_tick` | Int32 | 回合结束 tick |
| `official_end_tick` | Int32 | 官方结算 tick |
| `winner` | Int32 | 获胜方（2 = T，3 = CT） |
| `winner_side` | String | 获胜阵营 |
| `reason` | Int32 | 结束原因代码 |
| `reason_name` | String | 结束原因：`bomb_defused` / `target_bombed` / `ct_win` / `terrorists_win` / `target_saved` |
| `is_knife_round` | Boolean | 是否刀局 |

---

### 3.5 `kills`（击杀事件）

每条记录 = 一次击杀，含击杀者、被击杀者、助攻者的**位置与身份**。

| 字段 | 类型 | 说明 |
|------|------|------|
| `attacker_entity_id` / `attacker_entity_serial` | Int32 / UInt32 | 击杀者实体编号 |
| `attacker_steamid` / `attacker_name` / `attacker_side` | — | 击杀者身份 |
| `attacker_x` / `attacker_y` / `attacker_z` | Float32 | 击杀者位置 |
| `victim_*`（同上 8 列） | — | 被击杀者身份与位置 |
| `assister_*`（同上 8 列） | — | 助攻者身份与位置 |
| `weapon` | String | 击杀武器 |
| `headshot` | Boolean | 是否爆头 |
| `assist_flash` | Boolean | 是否闪光助攻 |
| `dominated` | Int32 | 支配（连续击杀同一人）计数 |
| `noscope` | Boolean | 是否不开镜击杀 |
| `penetrated` | Int32 | 是否穿墙击杀 |
| `revenge` | Int32 | 是否复仇击杀 |
| `thrusmoke` | Boolean | 是否穿烟击杀 |
| `hitgroup` | Int32 | 命中部位代码 |
| `hitgroup_name` | String | 命中部位：`head` / `chest` / `stomach` / `left_arm` / `right_arm` / `left_leg` / `right_leg` / `generic` |
| `is_trade` | Boolean | 是否补枪击杀 |
| `victim_traded` | Boolean | 受害者是否被队友补枪 |
| `tick` | Int32 | 事件 tick |

---

### 3.6 `damages`（伤害事件）

结构类似 `kills`，但记录**每次造成伤害**（非仅击杀）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `attacker_*` / `victim_*` | — | 双方身份与位置（同 kills） |
| `weapon` | String | 造成伤害的武器 |
| `dmg_health` | Int32 | 生命伤害 |
| `dmg_armor` | Int32 | 护甲伤害 |
| `hitgroup` / `hitgroup_name` | — | 命中部位 |
| `health_pre` / `health_post` | Int32 | 受害者生命值（前/后） |
| `armor_pre` / `armor_post` | Int32 | 受害者护甲值（前/后） |
| `tick` | Int32 | 事件 tick |

---

### 3.7 `shots`（开枪事件）

| 字段 | 类型 | 说明 |
|------|------|------|
| `tick` | Int32 | 开枪 tick |
| `entity_id` / `entity_serial` | — | 开枪者实体编号 |
| `steamid` / `name` / `side` | — | 开枪者身份 |
| `x` / `y` / `z` | Float32 | 开枪者位置 |
| `pitch` / `yaw` | Float32 | 枪口朝向（俯仰角 / 偏航角） |
| `weapon` | String | 武器 |
| `scoped` | Boolean | 是否开镜 |
| `inaccuracy` | Float32 | 开枪时武器精度 |
| `num_bullets_remaining` | Int32 | 剩余子弹数 |

---

### 3.8 `round_economy`（回合经济）

| 字段 | 类型 | 说明 |

| `round_num` | Int32 | 回合号 |

---

### 3.9 `grenades`（道具投掷）

| 字段 | 类型 | 说明 |
|------|------|------|

### 3.11 `snapshots_1s`（每秒玩家状态快照）⭐

> **热力图主数据源**。由 `demo.snapshots(seconds=1.0)` 生成，按秒对每名玩家采样。

**基础与位置**

| 字段 | 类型 | 说明 |
|------|------|------|
| `tick` | Int32 | 采样 tick |
| `steamid` / `name` / `side` | — | 玩家身份 |
| `x` / `y` / `z` | Float32 | 玩家位置（画热力图用 x/y） |
| `velocity_x` / `velocity_y` / `velocity_z` | Float32 | 速度分量 |
| `velocity` | Float32 | 速度大小 |
| `pitch` / `yaw` | Float32 | 视角朝向 |

**生命与装备**

| 字段 | 类型 | 说明 |
|------|------|------|
| `health` | Int32 | 生命值 |
| `armor` | Int32 | 护甲值 |
| `has_helmet` | Boolean | 是否有头盔 |
| `has_defuser` | Boolean | 是否有拆弹器 |
| `has_bomb` | Boolean | 是否携带 C4 |

**武器与道具**

| 字段 | 类型 | 说明 |
|------|------|------|
| `active_weapon` | String | 当前手持武器 |
| `primary_weapon` | String | 主武器 |
| `secondary_weapon` | String | 副武器 |
| `fire_grenades` | Int32 | 燃烧瓶/火 数量 |
| `smoke_grenades` | Int32 | 烟雾弹数量 |
| `he_grenades` | Int32 | 手雷数量 |
| `flashbangs` | Int32 | 闪光弹数量 |
| `decoy_grenades` | Int32 | 诱饵弹数量 |

**经济**

| 字段 | 类型 | 说明 |
|------|------|------|
| `equipment_value` | Int32 | 当前装备价值 |
| `equipment_value_round_start` | Int32 | 回合初始装备价值 |
| `money` | Int32 | 金钱 |

**动作与状态标志**

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_crouched` | Boolean | 是否蹲下 |
| `is_walking` | Boolean | 是否静步 |
| `is_jumping` | Boolean | 是否跳跃 |
| `is_in_bomb_zone` | Boolean | 是否在包点内 |
| `is_scoped` | Boolean | 是否开镜 |
| `is_reloading` | Boolean | 是否换弹 |
| `is_silent_reloading` | Boolean | 是否静音换弹 |
| `is_defusing` | Boolean | 是否正在拆弹 |
| `is_blinded` | Boolean | 是否被闪 |
| `flash_duration` | Float32 | 致盲剩余时长（秒） |
| `inventory` | String | 物品栏（JSON 字符串） |

## 4. 数据流与后续使用

```
demo 文件
   │  awpy (Rust 后端)
   ▼
Parquet 表格（本字典）
   │
   ├─ snapshots_1s ──────────► 走位热力图（阶段 1）
   ├─ kills / damages ───────► 交火 / 死亡热区（阶段 1）
   ├─ rounds + kills ────────► 失守区域判定（阶段 2）
   ├─ grenades / bomb / shots► 战术打法挖掘（阶段 2）
   ├─ round_economy + snapshots► 推荐系统 context（阶段 3）
   └─ 全部聚合统计 ──────────► LLM 战术报告（阶段 4）
```
